# Contact form setup (2 minutes)
1. Go to https://web3forms.com, enter shahimahmud123@gmail.com and get your free Access Key by email.
2. In contact.html replace YOUR_WEB3FORMS_ACCESS_KEY with that key (it is designed to be public; restrict it to your domain in the Web3Forms dashboard).
3. Deploy the folder to Netlify, Vercel or GitHub Pages, then send a test message.
